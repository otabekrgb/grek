# grek

Шахматы в браузере: движок grek (≈2300) и более слабый neo (≈1300),
голосовые реплики, разбор партий с точностью и грубой оценкой Elo.

Всё считается на сервере без внешних сервисов. Архив партий на хостинге
хранится в браузере игрока: у каждого посетителя свой.

## Хостинг

Docker-образ на Render, план Free. Порт берётся из переменной `PORT`,
включён режим `GREK_HOSTED=1` (архив в браузере, без записи на диск).

Обновление кода: из корня проекта выполнить

```bash
GH_USER=логин GH_TOKEN=токен bash hosting/publish.sh
```

Render подхватит новый коммит и пересоберёт образ сам.
